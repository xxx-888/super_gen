SceneGen AI短剧生成平台 — 工作日报
日期：2026-08-19

一、本期完成的核心功能

1. 【作品画廊】点赞体系 + 作品管理 + 封面智能截帧（画廊从演示页变完整闭环）
   - WorkLike 模型 + work_likes 迁移（work_id+user_id 唯一约束防重复点赞，
     级联删除）；点赞接口改为登录态切换（点赞/取消），并发双击唯一约束
     冲突兜底为已点赞；画廊列表/详情携带 liked_by_me（已赞红心高亮）
   - 新增 get_optional_user 公开接口依赖：带 token 返回用户、无 token 不抛
     401，公开画廊登录/未登录都可访问且登录时计算点赞态
   - 封面智能截帧：发布作品未提供封面时用 ffmpeg 从视频截 10%/25%/50%
     时刻候选帧，按「细节方差×亮度」评分选最优帧入库；ffmpeg 不可用优雅
     降级为无封面
   - 防重复发布：同一用户同一视频 URL 只允许发布一次（409 提示去
     「我的作品」编辑），发布自动携带 project_id/episode_id 溯源
   - 前端：公开画廊详情弹窗直接播放视频；「我的作品」Tab（编辑弹窗/
     上架下架/删除）；发布弹窗 PublishWorkModal 三处复用（集页分镜成片/
     完整成片、视频预览任务产物、画布输出节点），已发布视频标记已发布
   - 后台作品管理页 /admin/works：搜索/公开状态筛选/作者信息/视频预览/
     上下架/删除（级联清理点赞记录）

2. 【成片链路】合并成片（全新能力）+ 一键成片编排大修
   - video_compose 服务：分镜视频逐个转码规范化（统一分辨率/帧率/编码，
     等比缩放+黑边填充，无音轨补静音）后 concat 无损拼接为完整成片
   - POST /episodes/{id}/compose：全部分镜完成时按序合并，不提交生成
     任务/不扣积分；结果写 episode.meta.composed_video_url，集状态推进
     completed；集详情页「完整成片」卡片（播放/发布画廊/重新合并）
   - 一键成片根因修复：异步渠道（MiniMax 等提交即返回）曾被当同步结果
     处理——任务秒标 completed、urls 空、分镜无视频、无人轮询；现保持
     processing 并转后台轮询，完成后下载视频回写分镜
   - 编排防重：跳过已生成分镜（不重复提交/扣费，积分仅按待生成预估）；
     有活跃任务的分镜不再重复扣费；generating 状态残留但任务已消失时
     自愈为待生成；前端按全完成→合并/部分完成→生成分流并适配
     processing 态反馈

3. 【画布编辑器】连线即引用 + 上传素材节点 + 生成图存素材库
   - 连线即引用（核心机制）：连线素材自动在目标节点提示词写入 @名称
     （与手动 @ 同格式，编辑器可见可编辑），断线/删上游节点同步移除；
     双格式识别（芯片模板与裸名）防重复注入或删不净；后端把 @名称 展开
     为资源描述并入参考媒体
   - 生成节点新增「已连素材」芯片条（★标记主参考，配色与提示词编辑器
     对齐）；未入库生成结果连线自动分配稳定别名引用（媒体按连线传输）
   - 上传素材节点（全新）：本地图片/视频/音频上传作为参考输入，三种
     类型句柄按当前素材类型渲染，可连多个
   - 生成图存为素材库：文生图/图生图/融合结果图一键入库（名称实时查重/
     自动唯一名/选角色场景道具），入库后下游连线立即补写 @引用；资源被删
     显示失效可重新入库；重新生成自动清除入库关联
   - 输出节点重做：实时解析上游连线结果视频（上游跑完自动出现预览、
     生成中显示等待态），标题输入+发布，上游重新生成后可发新视频
   - 参考视频/音频连线：生成类节点新增 video/audio 参考句柄，多上游
     聚合（≤3）透传 reference_video/reference_audio
   - 画布链路 skip_ref_binding=true：适配器不注入参考绑定语，提示词
     原文即所发（绑定职责移交连线 @引用机制）
   - 交互：连线中点剪刀按钮删线（悬停高亮，替代选中线+退格隐式操作）

4. 【适配器】画布链路开关 + OpenAI 生图尺寸档位
   - MiniMax 适配器支持 skip_ref_binding（不注入参考绑定语）
   - OpenAI 生图尺寸档位体系：比例（横/竖/方）×分辨率档（1K/2K/3K）映射
     GPT 生图白名单尺寸，缺档向低档回退；gpt-image 质量只发 medium/high
     （low 升 medium、auto 固定 high），edits 接口同样支持质量档位
   - CompShare 渠道能力复测脚本（绕过适配器跳过逻辑直测
     reference_video/reference_audio，渠道方反馈支持后一键验证再切回开关）

5. 【集页创作面板】音视频参考元素
   - 元素类型扩展音频/视频（素材库选择器可选），URL 字段对应
     audio_url/video_url，参考媒体完整透传适配器组包

二、技术改进与修复

   - 一键成片 @引用展开：原样发送 @{type:uuid:name} 模板给模型是无效
     引用——抽 expand_scene_prompt_with_refs 共用助手（分镜生成/一键成片
     同一入口），引用媒体按 URL 去重收集（音视频各 ≤3）
   - 异步任务提交/完成/失败三阶段 meta.logs 累积：任务队列「接口日志」
     对异步渠道完整可追溯（此前提交阶段日志丢失、失败无日志）
   - 429 积分不足误报修复：后端把积分不足映射为 429，前端统一提示
     「操作过于频繁」让用户误判为限流——现识别 QUOTA_EXCEEDED 展示具体
     原因与充值路径
   - HighlightPrompt 支持 [类型:名] 展开格式高亮（后端展开后的提示词在
     任务队列等处展示不再纯文本）
   - 侧栏折叠态图标消失修复：Arco 折叠用 margin-right:100vw 顶走文字的
     技巧与 flex 菜单项冲突把图标挤到 0 宽，显式接管尺寸与压缩
   - 画布样式修复：节点聚焦黑框、output 节点命中 React Flow 内置样式
     出现黑边方块（双类名提高优先级覆盖）
   - 点赞切换不再误计浏览量（get_work 内部操作不计 view）
   - 前端 tsc 存量错误 46→38（净修复 8 个，本轮零新增）
