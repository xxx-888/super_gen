# SceneGen 产品化盘点 — 新增 / 完善 / 精简建议

> 2026-09-14 · 基于代码全景扫描（后端 262 端点 / 36 表 / 30 服务 / 11 模型适配器；前端 42 页面中 36 个挂载路由）

## 一、现状一句话

**「生产工具链」已经是完整且专业的（剧本→分镜→资源→生成→剪辑→发布→积分计费），但「产品闭环」缺三块：收钱的闭环（无在线支付）、召回用户的闭环（无通知触达）、获新客的闭环（无模板/引导/分享落地页）。** 同时历史演进留下了一批死代码和体积问题。

---

## 二、建议新增（按用户旅程排序）

### P0 · 商业与留存闭环

| 功能 | 理由 | 说明 |
|------|------|------|
| **在线充值（微信/支付宝支付）** | 目前积分只有后台人工充值，撑不起自助化产品；用户积分用尽即流失 | 套餐化（体验版/创作者/工作室）+ 支付回调入账 + 发票申请；支付前置要求：IAP 类目/商户号资质，与备案进度联动 |
| **生成完成通知（站内消息中心）** | 现在生成完成只能停留在打开的页面等 WS 轮询，关页即失联；视频生成动辄几分钟是最大的流失点 | 通知中心（铃铛+未读数）+ 生成完成邮件通知（邮件基础设施目前完全没有，需补 SMTP）；充值成功/审核结果也走同一通道 |
| **示例项目 / 模板库 + 新手引导** | 新用户注册后面对空项目不知从何下手，第一支片子的成功率决定留存 | 官方示例项目一键克隆（含剧本/分镜/提示词/资源全套）、按题材分类的剧本模板、首次登录分步引导 |

### P1 · 获客与自助化

| 功能 | 理由 |
|------|------|
| **作品分享落地页 + 公开页预渲染** | 画廊作品现在只能登录看；给每个公开作品一个免登录 view-only 落地页（带 og 卡片），配合爬虫预渲染，让作品成为获客素材——作品被分享到微信/抖音 = 免费投放 |
| **用户侧生成前费用预估** | 计价命中测试只有后台有；用户点生成前应显示「本次预计扣 X 积分」，配合积分不足引导充值，减少"生成完才发现没积分"的客诉 |
| **ComfyUI 直连执行收尾** | `comfyui_workflow.py` 已有 POST /prompt 提交逻辑，缺进度 WS 与队列查询——README 已宣传 ComfyUI 工作流库，补完才能兑现；也可评估直接砍掉该模块（见精简） |
| **邮箱验证 + 手机号更换/解绑** | 注册只验手机不验邮箱（无 SMTP 所致）；历史邮箱用户手机号丢失后无找回通道；手机号一旦绑定终身不可换，换机/换号即死号 |

### P2 · 规模化与出海

| 功能 | 理由 |
|------|------|
| **Celery 任务队列接通** | `app/tasks/` 里 celery_app/image_gen/video_gen/subtitle 全写好了但没接——生成目前靠进程内协程，重启即丢任务、无法横向扩容；规模化前必须接 |
| **接口级限流** | 验证码有冷却日限，但业务端点（生成/上传/AI 解析）无统一限流，防刷靠积分计费兜底 |
| **前端 i18n（zh/en）** | 客户名单里有 DramaBox/海外背景团队，出海是自然方向；i18n 越晚做成本越高 |
| **数据埋点与漏斗** | 无任何行为埋点，注册→首片转化率、各环节流失率全靠猜；接 Plausible/Umami 自托管或神策 |
| **作品多版本对比** | 同一分镜多参数生成的结果并排对比挑选——生成类产品的普遍刚需，当前只能逐个看 |

## 三、建议完善（已有功能补短板）

1. **积分不足引导链路**：生成失败自动退款已有，但「生成前余额检查 + 不足引导」提示弱
2. **项目回收站/软删除**：项目删除疑似级联硬删（剧本/分镜/画布连带），误删无法恢复——生产环境最痛的客诉来源
3. **任务历史页的用户侧体验**：任务列表已有，但失败原因对用户不友好（技术性日志直出），应翻译成人话 + 建议
4. **团队席位与套餐联动**：席位、配额、积分三者目前独立管理，套餐化时统一
5. **README/文档与 onboarding**：docs 里有架构文档，缺「5 分钟跑通第一支片子」的 Getting Started 视频或动图
6. **前后端遗留 422/403 文案统一**：越权/校验错误已有中文，继续收口（安全审计待办）

## 四、建议精简（历史演进的包袱）

| 项 | 依据 | 动作 |
|----|------|------|
| **6 个死页面** | App.tsx lazy import 但未挂任何路由：SceneEditorPage、VideoOverviewPage、TeamCreditsPage、TeamMemberGroupsPage、TeamPermissionGroupsPage、TeamMaterialPermissionsPage | 删文件 + 删 import + 保留路由重定向兜底旧链接 |
| **旧场景编辑器目录** | `pages/scene/` 整目录已被 Canvas/EpisodeEditor 替代，仅路由重定向引用 | 随死页面一起清理 |
| **CreationPanelPage / WorkbenchPage 文件** | 功能已合并进 CanvasPage，文件仍在仓库 | 确认无引用后删除 |
| **main bundle 660KB** | index-DPYbkZA7.js 660KB（gzip 198KB），vite 已警告 | manualChunks 拆 vendor（arco/react-flow/tiptap 分包），首屏可再快 30%+ |
| **team 旧路由重定向层** | 4 条旧路径重定向仅服务于老书签 | 保留 1-2 个版本后移除 |
| **eslint 9 迁移** | lint 脚本挂在旧版 | 与前端清理一起做 |
| **docs/PLAN_jurilu_features.md** | 早期复刻方案，已完成使命 | 归档或删除 |

> 精简原则：**只删「确认无引用 + 有路由重定向兜底」的代码**，全部操作可一次 PR 完成并回滚。

## 五、优先级路线建议（一个季度视角）

```
第 1 个月   精简清理 PR（死页面/分包/eslint）+ 邮箱 SMTP 基建
            + 生成完成通知（站内+邮件）—— 留存止血
第 2 个月   示例项目/模板库 + 新手引导 + 用户侧费用预估 —— 首片转化
第 3 个月   在线充值套餐化（依赖商户号/备案进度）+ 作品分享落地页 —— 商业闭环
持续并行    Celery 接通（有大客户/并发压力时提前）、埋点
```

**北极星指标建议**：新注册用户 7 天内完成首支成片的比例（当前无埋点，先补埋点才能量化上面每一步）。
