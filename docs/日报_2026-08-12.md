SceneGen AI短剧生成平台 — 工作日报
日期：2026-08-12
====================================

一、本期完成的核心功能

1. 【画布面板】节点画布编辑器（全新功能）
   - 基于 React Flow 实现可视化节点画布，替代原有的「工作台」+「创作面板」
   - 8种节点类型：文生图、融合生成、图生视频、首尾帧生视频、语音合成、对口型、输出
   - 节点拖拽创建、连线建立数据流、参数配置、一键运行
   - 每个节点内置提示词编辑器（支持@引用角色/场景/道具），弹出宽屏抽屉编辑
   - 模型/尺寸/分辨率/质量/水印等参数每个节点独立设置
   - 运行结果缩略图预览（contain完整显示）、点击放大、重新生成
   - 画布数据持久化到后端（graph_data整存整取 + 乐观锁version）
   - 运行时状态（_status/_result）保存后刷新可恢复
   - 异步任务提交 + 轮询模式（async_submit），不受HTTP超时限制

2. 【Agent向导】剧本驱动4阶段创作流程（优化完善）
   - 阶段1：可选已有剧本 + 保留手动粘贴，解析后自动创建/关联Script到Episode
   - 异步解析（gen_task_tracker），解决LLM解析超过30s超时的问题
   - 阶段2：资产详情（角色/场景/物品关联），已有分镜不重新拆分（防覆盖）
   - 阶段3：分镜管理，支持勾选/编辑/删除单个分镜
   - 阶段4：视频编辑，每分镜独立参数设置，一键生成弹参数框
   - 历史进度恢复横幅，刷新/重开后一键恢复到上次阶段
   - 剧本选择列表标记已解析状态

3. 【集号对应】剧本解析集号精确匹配修复
   - 新增 _extract_episode_number() 从标题提取真实集号（中文/阿拉伯/英文）
   - Episode.number 不再盲目max+1，优先用剧本真实集号
   - 分集预览显示真实集号（不再用数组下标i+1）

4. 【一键成片】确认+进度+结果汇总
   - 弹确认框显示分镜数+预估积分
   - 无分镜时不再强制推进状态，返回友好提示
   - 完成后弹结果汇总（成功/失败统计+失败分镜序号）

5. 【OpenAI适配器】GPT Image文生图真实接入
   - 新增OpenAIAdapter（dall-e-3/gpt-image-1/gpt-image-2）
   - 支持url和b64_json两种响应格式
   - b64图片自动保存到本地（save_b64_to_local）
   - 质量映射：平台hd→OpenAI high，standard→medium
   - 资源管理生图模型列表改为动态加载（替代硬编码）

6. 【提示词编辑器优化】
   - @引用缩略图预览面板（按类型分组，contain完整显示原图比例）
   - 默认折叠摘要行，点击展开看缩略图
   - 点击缩略图放大预览

7. 【后台管理】
   - 模型配置表格状态列改为行内Switch开关（启用/禁用）
   - 禁用的模型立即从所有下拉列表和API调用中移除

8. 【移除快速生成】
   - AgentPanel（快速生成）功能移除，合并到Agent向导


二、技术改进

- 画布节点异步执行模式：async_submit参数，后端创建task后立即返回task_id
  适配器在后台asyncio.create_task执行，前端轮询GET /tasks/{task_id}
- 画布自动保存防抖2s，回退/Steps切换不更新后端wizard_stage（保留最远进度）
- 资源管理模型选择修复：AIModel.id → 从DB查完整配置构造适配器
- httpx timeout=None（后台任务不限制等待时间）
