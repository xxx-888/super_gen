====================================
SceneGen AI短剧生成平台 — 工作日报
日期：2026-08-18
====================================

一、本期完成的核心功能

1. 【CompShare 渠道】优云智算 ModelVerse MiniMax-H3 视频适配器（全新渠道接入）
   - 新增 MinimaxCompshareAdapter：协议与官方 /v2 一致，继承复用官方适配器，
     仅覆盖渠道差异（base_url、仅 768P、强制无水印、提示词 5000 字上限）
   - 支持任务取消（DELETE /v2/video_generation/{task_id}），接入现有取消链路
   - endpoint 容错（裸域名自动补 /minimax）、后台模型页 provider 选项/预设/超时配置
   - 「测试连接」从形式校验升级为真实鉴权探测（假 task_id 查询，非 401 即 Key 有效）
   - 渠道能力实测定位：reference_video/reference_audio 参数未实现（任意 URL 均返回
     RetCode 230，图片 URL 参考可正常服务端下载）——适配器自动跳过并写任务日志警告，
     官方适配器保留发送能力，渠道实现后改回一个开关即恢复

2. 【参考生成链路】三轮根因修复，参考图真正生效
   - data URI MIME 修正：按文件头魔数识别真实格式（实测 uploads 163 张图 120 张
     扩展名与字节不符，JPEG 存成 .png），服务端校验 content-type 不再 400
   - r2va 参考模式修复：image_url（分镜图）与 @引用参考图共存时参考图被静默丢弃，
     现统一走参考模式（MiniMax 规定首尾帧与参考素材互斥）；prompt 自动注入
     「参考图N/视频N/音频N」绑定指令（H3 依赖显式指代，无绑定语参考权重极弱）
   - @引用展开补全：画布/创作面板链路（/creation/fusion 等）此前不解析 @芯片，
     提示词模板原样进模型且参考图不发送——现 _run 统一入口自动展开引用并把
     引用资源媒体并入参考素材（分镜 clip 链路原有逻辑不变）

3. 【视频资源体系】项目级视频资产 + @视频/@音效引用（全新资源类型）
   - VideoAsset 模型 + alembic 迁移（video_assets 表）+ CRUD 接口
   - @引用全链路支持视频类型（prompt_builder 解析/孤儿回退/预览/展开）
   - 生成链路：@视频 → reference_video（≤3）、@音效 → reference_audio（≤3）、
     参考图 ≤9，本地文件自动转 data URI（视频/音频 MIME 魔数嗅探），渠道不收
     data URI 时自动跳过并警告不阻断
   - 前端：资源管理「视频管理」Tab（上传/URL 添加/编辑/点击播放预览）、项目页入口、
     素材库同步目标支持音频/视频、@候选下拉按类型分组（角色/场景/道具/音效/视频）
   - 素材库两页 + 资源管理 + 画布节点全量视频/音频点击预览播放（弹窗播放器/内嵌试听）

4. 【独立文件服务器】fileserver/ 全新可部署服务（公网文件托管）
   - 单文件 FastAPI：上传（鉴权）/直链下载（公开，供渠道拉取）/列表/删除/统计，
     API Key 鉴权、按年月分目录、500MB 上限、扩展名白名单，附 Dockerfile 与部署文档
   - backend 集成：视频/音频/图片上传自动转传拿公网直链（后台系统设置页可配地址/
     API Key，DB 设置优先于 .env，显式清空=停用云端；「测试连接」做上传/直链下载/
     删除全链路探测）
   - 双写开关（默认开）：云端+本地各一份；视频/音频记录云端直链（渠道需公网下载）、
     图片记录本地地址（模型读取更快）云端留备份；未配置/转传失败降级本地
   - 已部署联调：186.241.125.144:9000 端到端验证通过（上传/直链/清理）

5. 【图生图】OpenAI Images Edits 接入（gpt-image 系列）
   - image_to_image/image_edit：参考图（节点上传/连线/@引用，≤4 张，本地/公网自动
     读取+魔数识别）→ multipart edits 生成新图；fusion 检测到参考图自动切 edits 链路
   - 画布新增「图生图」节点：内嵌参考图上传位（点击预览）、参数区、提示词置底
   - 画布新增「视频生视频」节点：参考视频+新脸参考图双上传位，走 reference_video
     链路（穿着/动作保持、换脸场景）

6. 【语音合成】OpenAI 兼容 TTS 适配器 + AI 生成音频（全新能力）
   - 新增 OpenAITTSAdapter（POST /audio/speech 协议）：硅基流动 CosyVoice（默认预设）、
     OpenAI tts-1、同协议平台均可接入；生成 MP3 落本地存储
   - 资源管理「音效管理」新增「AI 生成音频」：名称/类型/文本/音色 → 直接生成落库，
     @引用即可使用；画布 TTS 节点 / /creation/tts 链路自动打通

7. 【画布编辑器】节点体系与连线逻辑大修
   - 布局统一：生成结果预览置顶、提示词编辑器置底；补齐视频/首尾帧/融合节点缺失的
     提示词编辑器（此前只 import 未渲染，节点无法输提示词）
   - 任意生成节点支持本地上传图片/视频：上传即注册项目资源（图片弹窗选类型/名称，
     视频自动建资产），@引用可直接使用
   - 连线修复（两个深层 bug）：ref1/ref2/ref3 编号句柄按前缀解析类型失效导致融合
     节点参考口形同虚设；first_frame 句柄类型索引与收集分支混用导致首尾帧收集回归
     ——现按注册表构建句柄类型索引表（校验用）+ 句柄 ID 路由（收集用）解耦
   - 连线放宽：image 输出可连 ref 输入（生成图直接作为下游参考）；参考类输入多上游
     聚合（按连线顺序全量收集），首帧类取第一张其余转附加参考
   - 节点内上传参考图/视频支持点击预览（图片大图/视频播放）
   - 顶部工具栏新增「连线图例」帮助：五色句柄对照表 + 连线规则 + 节点颜色分组

8. 【素材互通】资源管理音效/视频支持从素材库导入
   - MaterialPickerModal 从三类（角色/场景/道具）扩展为五类（+音效/视频）：
     分类映射/目标类型/已导入判断（url 字段）/新建表单按类型适配
   - 素材库上传的视频走文件服务器转传，导入后参考视频直接可用公网直链
